Control Room for staged agent work.

Each board column is an isolated LLM agent. Cards move only after a human gate, unless you mark a stage auto-advance. First production-ready cut is 0.0.1 — not published yet.

Shipping in v0.0.1

  • Local Electron IDE: norns init / norns run
  • Visual state machine, including parallel split and join
  • Human approve/reject gates; agent recommendation is advisory
  • Fresh schema only — norns init --force wipes the local database
  • Production refuses admin/admin and requires secure cookies
  • Compose backend/worker image is baked at build time

Not in this cut

  • Schema migrations — Alembic starts when 0.0.1 is published
  • Multi-user accounts, teams, or RBAC
  • A hosted Control Room. This is a local IDE, not SaaS
  • Polarion field writes still need hardening if you use that connector

Try the coming cut

From the 0.0.1 branch. Init prints a generated admin password. Existing ~/.norns does not upgrade in place.

git clone https://github.com/YanChao1999/Norns.git
cd Norns
git checkout cursor/v0.0.1-first-production
uv sync
cd frontend && npm install && npm run build && cd ..
bash scripts/stage-ui.sh
npm install --prefix norns/electron
uv run norns init --force
uv run norns run
